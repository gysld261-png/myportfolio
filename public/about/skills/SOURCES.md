# Skills icons

Figma, HTML5, JavaScript, TypeScript, React and GitHub SVGs are vendored from
[Devicon](https://github.com/devicons/devicon), revision
`7330accdbc47e2dc0c19789a48533c4a3c50fe58`.

Original paths: `icons/{name}/{name}-original.svg`.
The upstream MIT license is retained in `LICENSE-devicon.txt`.
Brand marks remain the property of their respective owners.

Prototyping is a custom generic SVG in `SkillsToolkit.jsx`.
Adobe applications use small text initials rendered in HTML/CSS, not downloaded artwork.
