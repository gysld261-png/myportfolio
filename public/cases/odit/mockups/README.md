# ODIT detail mockup

[Figma 목업 원본](https://www.figma.com/design/hEKHltlCyGEM6LywJ60Ylw?node-id=2125-1210) — `디자인 · 타입 정리` 페이지의 `odit-detail-mockup`.

- `detail-mockup.webp`: 2880×1800, 상세 소개 아래 전체 폭 이미지 1장.
- 사용한 화면은 사용자가 지정한 홈 `2024:573`, 오딧맵 `2024:878`, 배지 `2024:849`뿐이다. 같이 지정된 탐색 `2024:778`은 사용하지 않았다.
- 원본 화면을 같은 비율의 이미지로 넣어 글꼴·문구·UI를 그대로 유지했다. 기기 프레임·각도·그림자와 배경은 Figma에서 편집할 수 있다. 화면 내부를 수정할 때에는 원본 UI를 편집한 뒤 다시 내보낸다.
- 별도의 설명 문구나 외부 사진·생성 이미지는 넣지 않았다. 상세의 실제 동선은 기존 VIEW PROTOTYPE 링크로 확인한다.
- Figma PNG 1× 내보내기 후 같은 크기의 WebP(quality 94)로 변환했다.
- 앞서 만든 `../prototype/`의 5장은 보관용이며 현재 상세에서는 사용하지 않는다.
